# inneRVoice

Mock interview practice and meeting assistant for Windows.

## Download

- Grab the latest installer from the [Releases](https://github.com/ajayvaineela/innervoice-releases/releases) page, or
- Install with winget:

  ```
  winget install InnerVoiceCloud.inneRVoice
  ```

Website: https://www.innervoice.cloud
